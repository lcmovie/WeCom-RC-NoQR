# WeCom-RC-NoQR

适用于 Windows PC 被远控场景的企业微信二次扫码验证绕过方案。

部分用户在远控环境使用企业微信时，会遇到手机扫码安全验证。本工具针对 Windows 企业微信 5.0.13.6005 的一处窗口规则命中分支进行修改，供有相同问题的用户测试。


## 适用范围

- Windows，Python 3.9 或更高版本，无需安装第三方 Python 库。
- 目前仅验证企业微信 5.0.13.6005 版本，其他版本自测。
- 工具通过完整 SHA-256 识别文件，同版本但哈希不同也会停止修改。
- 修改后腾讯数字签名会显示 `HashMismatch`。如客户端启动或使用异常，可使用工具恢复原版。
- 软件更新可能覆盖修改，其他风控信号仍可能触发扫码验证。

## 下载

[下载 v0.1.0 分享包](./WeCom-RC-NoQR-v0.1.0.zip)，解压后按下面步骤操作。源码和使用说明也可直接从仓库下载。

## 使用方法

1. 解压本压缩包，保留其中的 `patch_wecom.py`。
2. 完全退出企业微信，包括托盘后台进程。
3. 在解压目录打开 PowerShell。先运行下面的查询命令，将示例路径换成自己安装的 `WXWork.exe` 完整路径。

```powershell
python .\patch_wecom.py info "D:\Program Files\WXWork\WXWork.exe"
```

4. 显示“匹配原版”后，执行修改。

```powershell
python .\patch_wecom.py patch "D:\Program Files\WXWork\WXWork.exe"
```

5. 显示“修改完成，文件哈希校验通过”后，启动企业微信并在原来会出现问题的远控条件下测试。若提示权限不足，以管理员身份打开 PowerShell，再执行相同命令。

工具会在主程序同目录保存 `WXWork.exe.singlepoint-original.bak`，并核对其哈希。请保留该文件用于恢复。如果系统使用 `py` 启动 Python，可将上述命令中的 `python` 换成 `py -3`。

## 恢复原版

先完全退出企业微信，再执行下面的命令。备份文件需要保留在主程序同目录。

```powershell
python .\patch_wecom.py restore "D:\Program Files\WXWork\WXWork.exe"
```

显示“恢复完成，原版哈希校验通过”后，再启动企业微信。如果主程序已被更新，工具会因哈希不匹配而停止。此时应使用官方安装包修复安装。

## 修改内容

工具只修改一处 6 字节指令并重算 PE 校验和。它让窗口规则匹配之后走原有的零匹配清理路径，跳过该次命中日志、命中上报处理和状态写入。

| 项目 | 值 |
| --- | --- |
| 主程序版本 | 5.0.13.6005 |
| 文件偏移 | `0x07FA18D4` |
| 原始字节 | `0F 84 5A 01 00 00` |
| 修改字节 | `E9 5B 01 00 00 90` |
| 跳转目标，首选虚拟地址 | `0x083A2434` |

原版 SHA-256 为 `9f7dcb2a085c9a379adbc9a3375d6d314f6cf101f2517b211f1902a261c9f242`。

修改版 SHA-256 为 `182b59c26e6bb6280810af7f0fa133d79d3979b5938634e21931fc052d0ae7bd`。
